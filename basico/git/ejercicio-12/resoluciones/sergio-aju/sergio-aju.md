# Sistema de Gestión de Reservas

Este proyecto es una herramienta para la administración eficiente de reservas de viajes, diseñada para mantener un registro claro, validar reglas de negocio y gestionar políticas de impuestos.

## Descripción
El sistema permite:
* Registrar nuevos destinos al catálogo.
* Validar automáticamente la edad mínima del usuario para procesar una reserva.
* Calcular y actualizar las políticas de impuestos aplicables al sistema de pagos.

## Características Técnicas
* **Control de versiones:** Git (siguiendo buenas prácticas de commits).
* **Lógica de negocio:** Implementada con validaciones estrictas para asegurar la integridad de los datos.
