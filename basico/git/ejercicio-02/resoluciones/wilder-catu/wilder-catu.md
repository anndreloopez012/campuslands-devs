# Clonación y Verificación del Repositorio

## Descripción

Se realizó la clonación del repositorio proporcionado para trabajar con una copia local del proyecto y verificar su estado inicial.

## Actividades realizadas

1. Se clonó el repositorio en el equipo local.
2. Se ingresó al directorio del repositorio clonado.
3. Se ejecutó el comando `git status` para verificar el estado del repositorio.
4. Se identificó la rama activa en la que se encontraba el repositorio.
5. Se creó un archivo de notas para registrar las observaciones obtenidas durante el ejercicio.

## Resultado

- Repositorio clonado correctamente.
- Estado del repositorio verificado mediante `git status`.
- Rama activa identificada.
- Archivo de notas creado con las observaciones del ejercicio.
