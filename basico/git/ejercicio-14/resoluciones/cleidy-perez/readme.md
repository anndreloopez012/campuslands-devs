# Pull Request de Laboratorio Químico

## Nombre

Cleidy Pérez

## Objetivo

Simular el proceso completo de creación de una Pull Request utilizando una rama personal.

## Proceso

1. Crear una rama desde `dev`.
2. Agregar la solución en la carpeta personal.
3. Realizar el commit.
4. Hacer push al repositorio remoto.
5. Redactar la descripción del Pull Request.
6. Verificar que solo se modificó la carpeta personal.

## Resultado

La solución quedó preparada para ser revisada mediante un Pull Request.

## Validación

### Caso normal

La carpeta contiene todos los archivos requeridos.

### Caso límite

No se modificó ningún archivo fuera de `resoluciones/cleidy-perez/`.
