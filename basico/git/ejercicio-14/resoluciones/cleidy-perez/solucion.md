# Solución

## Tema

Fórmulas químicas

## Objetivo

Preparar una entrega simulando un Pull Request de un proyecto colaborativo.

## Proceso realizado

1. Se creó una rama personal desde `dev`.
2. Se agregó la solución dentro de la carpeta `resoluciones/cleidy-perez/`.
3. Se realizaron los cambios necesarios.
4. Se hizo el commit con un mensaje descriptivo.
5. Se hizo push de la rama al repositorio remoto.
6. Se preparó la descripción del Pull Request.

## Resultado

La solución quedó lista para ser revisada mediante un Pull Request.
