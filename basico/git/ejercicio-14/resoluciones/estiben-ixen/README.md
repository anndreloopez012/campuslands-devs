# Pull Request - Laboratorio químico

## Nombre

Estiben Ixen

## Objetivo

Crear una solución relacionada con fórmulas químicas aplicando un flujo de trabajo colaborativo con Git mediante una rama personal y una entrega simulando un Pull Request.

## Cambios realizados

* Se creó la rama personal a partir de `dev`.
* Se agregó la solución dentro de:

```
basico/git/ejercicio-14/resoluciones/nombre-apellido/
```

* Se documentó el proceso realizado y la validación de la solución.
* Se realizó commit con un mensaje descriptivo.
* Se subieron los cambios mediante `git push`.

## Solución

La solución fue desarrollada siguiendo estos pasos:

1. Identificación de los datos de entrada relacionados con la fórmula química.
2. Procesamiento de la información utilizando una estructura clara y ordenada.
3. Generación del resultado esperado.
4. Validación con diferentes casos de prueba.

## Validación realizada

Caso normal:

* Se ingresaron datos válidos y se verificó que la solución generara el resultado esperado.

Caso límite:

* Se probaron valores vacíos o condiciones especiales para comprobar el manejo correcto de errores.

## Evidencia Git

Comandos utilizados:

```bash
git status
git add .
git commit -m "Agrega solución ejercicio 14 laboratorio químico"
```

La entrega quedó preparada para revisión mediante Pull Request, respetando la estructura solicitada y sin modificar archivos pertenecientes a otros participantes.
