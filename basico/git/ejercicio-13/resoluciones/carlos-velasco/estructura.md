# Estructura del Proyecto de Animación 3D

## Proyecto

El proyecto se organiza en diferentes áreas de trabajo para facilitar el desarrollo colaborativo.

## Áreas

### Modelado

- Creación de personajes.
- Modelado de escenarios.
- Optimización de mallas 3D.

### Renders

- Configuración de iluminación.
- Renderizado de escenas.
- Exportación de imágenes y videos.
