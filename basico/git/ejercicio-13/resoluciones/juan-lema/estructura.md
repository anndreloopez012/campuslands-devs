# Estructura del proyecto

## Modelado 3D

- Personajes principales modelados en baja poligonizacion.
- Props de escenario listos para texturizado.
- Rigging basico aplicado a personaje protagonista.

## Renders

- Render de escena principal en resolucion 1080p.
- Iluminacion ajustada con tres puntos de luz (key, fill, back).
- Render de turnaround del personaje protagonista.
