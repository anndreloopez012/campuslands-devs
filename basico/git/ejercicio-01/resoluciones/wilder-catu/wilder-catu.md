# Inicialización del Repositorio Git

## Objetivo

Configurar el repositorio para comenzar el control de versiones del proyecto.

## Procedimiento

### 1. Inicializar el repositorio

```bash
git init
```

### 2. Agregar los archivos al área de preparación

```bash
git add .
```

### 3. Crear el primer commit

```bash
git commit -m "Commit inicial del proyecto"
```

### 4. Verificar el historial de commits

```bash
git log --oneline
```

## Resultado esperado

- El repositorio queda inicializado.
- Los archivos son registrados por Git.
- Se crea el primer commit del proyecto.
- El historial muestra el commit inicial correctamente.
