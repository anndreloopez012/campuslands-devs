# Checklist final de flujo profesional

## Nombre

Estiben ixen

## Objetivo

Aplicar un flujo de trabajo profesional utilizando Git, integrando ramas, commits, sincronización con `dev` y una revisión final antes de la entrega.

## Actividades realizadas

1. Se creó una rama personal desde `dev`.
2. Se desarrolló una solución dentro de la carpeta asignada.
3. Se registraron los cambios mediante un commit descriptivo.
4. Se actualizó la rama con los cambios más recientes de `dev`.
5. Se enviaron los cambios al repositorio remoto.
6. Se completó una revisión final utilizando un checklist de entrega.

## Validación

Se verificó que:

* La solución se encuentra en la carpeta `resoluciones/nombre-apellido/`.
* No se modificaron archivos base del ejercicio.
* La rama quedó sincronizada con `dev`.
* La entrega está lista para revisión mediante Pull Request.

## Evidencia

Comandos utilizados:

```bash
git checkout -b nombre-rama
git status
git add .
git commit -m "Completa ejercicio 15 de Git"
git pull origin dev
git push origin nombre-rama
git log --oneline
```

## Resultado

La entrega cumple con el flujo de trabajo solicitado y sigue las buenas prácticas de organización, control de versiones y preparación para revisión colaborativa.
