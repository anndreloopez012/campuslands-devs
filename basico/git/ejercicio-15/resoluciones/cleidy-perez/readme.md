# Checklist Final de Flujo Profesional

## Nombre

Cleidy Pérez

## Objetivo

Simular un flujo profesional de trabajo con Git, integrando ramas, commits, actualización con `dev`, `push` y revisión final.

## Proceso

1. Crear una rama desde `dev`.
2. Agregar una solución pequeña.
3. Realizar un commit con un mensaje descriptivo.
4. Actualizar la rama con los cambios de `dev`.
5. Hacer `push` al repositorio remoto.
6. Verificar el estado del proyecto.
7. Preparar la entrega para revisión.

## Resultado

La solución quedó lista para crear un Pull Request y ser revisada.

## Validación

### Caso normal

La rama está actualizada y no hay cambios pendientes.

### Caso límite

Solo se modificó la carpeta personal y no se alteraron archivos del proyecto base.
