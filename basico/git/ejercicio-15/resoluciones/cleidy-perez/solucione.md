# Solución

## Tema

Ropa y proyectos reales

## Objetivo

Simular un flujo de trabajo profesional utilizando Git para preparar una entrega colaborativa.

## Proceso realizado

1. Se creó una rama personal desde `dev`.
2. Se agregó la solución en la carpeta `resoluciones/cleidy-perez/`.
3. Se realizó un commit con un mensaje descriptivo.
4. Se actualizó la rama con los cambios de `dev`.
5. Se hizo `push` de la rama al repositorio remoto.
6. La solución quedó lista para revisión mediante Pull Request.
