# Ejercicio 05: Sistema de Taller de Motos

**Estudiante:** Irma Arias

## Descripción
Estructura modular diseñada para la gestión de órdenes de reparación en un taller de mecánica.

## Estructura de Módulos
- `modules/clientes/`: Almacena información personal y contactos de los dueños.
- `modules/motos/`: Registra datos técnicos (placa, chasis, modelo).
- `modules/ordenes/`: Gestiona el flujo de trabajo, costos y estado de reparación.
