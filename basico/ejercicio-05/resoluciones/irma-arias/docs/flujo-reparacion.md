# Flujo de Reparación - Taller de Motos

El proceso sigue estos pasos:
1. **Recepción:** Se registra al cliente y los datos de la moto.
2. **Diagnóstico:** Se genera una orden de servicio con los síntomas detectados.
3. **Reparación:** El mecánico interviene según lo detallado en la orden.
4. **Entrega:** Se finaliza la orden y se notifica al cliente para el retiro.
