# Ejercicio 13 

# Explicacion 
En este ejercicio se implementó un recorrido sobre el arreglo de jugadores utilizando un ciclo for tradicional para evaluar la cantidad de partidos de cada participante. Esto permitió realizar una validación de seguridad contra divisiones por cero, calcular de forma precisa el porcentaje de victorias (winrate) y la diferencia de puntos, y finalmente ordenar el ranking de manera descendente para mostrar los resultados en la consola.
