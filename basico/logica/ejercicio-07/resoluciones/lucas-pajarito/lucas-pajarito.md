# README - Sistema de Diagnóstico de Motocicletas

## Objetivo

Este programa simula un sistema básico de diagnóstico para motocicletas. Su propósito es recibir uno o varios síntomas de una motocicleta, analizarlos y proporcionar una recomendación para cada uno.

## Funcionamiento

* Recibe un arreglo con los síntomas detectados.
* Evalúa cada síntoma mediante la función `diagnosticar(sintomas)`.
* Asigna una recomendación según el problema identificado.
* Genera un reporte final con el diagnóstico y la acción recomendada para cada síntoma.

## Resultado

Al ejecutar el programa, se muestra en la consola un reporte con los síntomas ingresados y las recomendaciones correspondientes, facilitando una evaluación rápida del estado de la motocicleta.
