# Ejercicio 12

# Explicacion 
En este ejercicio se implementó un recorrido sobre el arreglo de prendas utilizando un ciclo for tradicional para evaluar el inventario de cada artículo. Esto permitió realizar una validación de control para detectar niveles de stock bajos, calcular de forma precisa la reposición sugerida basada en las ventas semanales evitando valores negativos, y finalmente mostrar un reporte detallado organizado por talla.
