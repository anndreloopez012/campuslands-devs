# Ejercicio 11

# Explicacion 
En este ejercicio se implementó un recorrido sobre el arreglo de reservas utilizando un ciclo for tradicional para evaluar los datos de cada viajero. Esto permitió realizar una validación de seguridad para filtrar las actividades extremas según la edad mínima requerida, calcular de forma precisa el costo total aplicando el impuesto del 12% a las reservas válidas, y finalmente generar un resumen organizado con los registros aprobados en la consola.
