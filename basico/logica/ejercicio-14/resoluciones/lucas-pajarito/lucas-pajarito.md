# Gestión de Compuestos Químicos

## Objetivo

Desarrollar un programa en JavaScript que permita almacenar información de distintos compuestos químicos, validar sus componentes y calcular el peso total de cada compuesto.

---

## Funcionalidad del código

El programa realiza las siguientes tareas:

1. Registra varios compuestos químicos.

2. Cada compuesto contiene:
   - Nombre del compuesto.
   - Lista de componentes.

3. Cada componente almacena:
   - Símbolo químico.
   - Cantidad de gramos.

4. Valida que todos los componentes tengan una cantidad de gramos mayor que cero. Si algún componente posee un valor menor o igual a cero, el compuesto completo se considera inválido.

5. Calcula la suma total de gramos de cada compuesto válido.

6. Filtra automáticamente los compuestos incompletos o inválidos para que no aparezcan en el resultado final.

---

## Resultado esperado

Al ejecutar el programa se obtiene:

- Validación de los gramos de cada componente.
- Eliminación de los compuestos con datos incorrectos.
- Cálculo del peso total de cada compuesto válido.
- Presentación de los componentes y el total de gramos de cada compuesto.

---

## Conclusión

Este ejercicio permitió aplicar el manejo de arreglos de objetos anidados, validaciones de datos, estructuras de control, recorridos mediante ciclos y filtrado de información utilizando JavaScript. Además, se reforzó el cálculo de datos derivados a partir de la información almacenada en cada compuesto químico.
