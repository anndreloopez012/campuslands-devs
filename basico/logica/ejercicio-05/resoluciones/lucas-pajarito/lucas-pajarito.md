# Ejercicio 05 Logica

## Descipcion.

Este ejercicio esta diseñado para desarrolar la logica de ordenamiento, cada aspecto debe ser evaluado cuidadosamente para evitar errores en sintaxis y desarrollo de codigo.


## Proyecto: Gestión y Análisis de Equipos de Fútbol

## Descripción

Este proyecto fue desarrollado en JavaScript con el propósito de practicar el manejo de arreglos de objetos, estructuras de control y métodos de iteración como forEach() y sort().

El programa almacena información de varios equipos de fútbol y realiza diferentes operaciones para analizar su desempeño durante un torneo.

# Objetivos
Almacenar información de varios equipos mediante un arreglo de objetos.
Calcular estadísticas básicas a partir de los datos registrados.
Validar el rendimiento de cada equipo según sus resultados.
Ordenar los equipos de acuerdo con un criterio determinado.
Practicar el uso de funciones, condicionales y métodos de arreglos en JavaScript.

# Estructura de los datos

Cada equipo contiene la siguiente información:

nombre: Nombre del equipo.
victorias: Cantidad de partidos ganados.
derrotas: Cantidad de partidos perdidos.
empates: Cantidad de partidos empatados.
golesAFavor: Total de goles anotados.
golesEnContra: Total de goles recibidos.
Funcionalidades

El programa permite:

Registrar varios equipos en un arreglo de objetos.
Calcular estadísticas de cada equipo.
Comparar el rendimiento entre equipos.
Ordenar los equipos según el criterio establecido (por ejemplo, cantidad de victorias o diferencia de goles).


Mostrar mensajes informativos sobre el desempeño de cada equipo utilizando estructuras condicionales.
Tecnologías utilizadas
JavaScript (ES6)
Conceptos aplicados
Arreglos de objetos.
Funciones.
Métodos forEach(), sort() y otros métodos de arreglos.
Condicionales (if / else).
Operadores aritméticos y de comparación.
Manipulación de objetos.
Ejecución
Clonar o descargar el proyecto.
Abrir el archivo .js en un editor como Visual Studio Code.
Ejecutar el programa con Node.js o desde la consola del navegador.
Propósito académico

Este proyecto tiene un propósito educativo y busca fortalecer el uso de estructuras de datos en JavaScript, así como la implementación de lógica para analizar información almacenada en objetos y arreglos.
