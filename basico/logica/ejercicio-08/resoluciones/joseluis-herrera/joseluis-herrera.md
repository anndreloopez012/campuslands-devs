# Ejercicio 08

## Explicacion 
En el siguiente ejercicio se hizo un filtrad de autos haciendo un recorrido con un ciclo for el cual le puse una condicion que solo diera los carros que
se hacen 3s para llegar a 100km, luego de eso se clasifico cuales autos eran exclusivos o contaban con pocas unidades y se metio en una variable llamada
filter para luego calcular el precio de los autos de la variable filter o lista filter y por ultimo se hizo un ranking de top 3 carros.
