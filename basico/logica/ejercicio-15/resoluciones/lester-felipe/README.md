## Este ejercicio fue creado con el objetivo de Calcular costo de producción por escena y detectar escenas costosas.

## Alumno: Lester Garcia

## Explicación general del ejercicio:

**El programa en JavaScript procesa un inventario de escenas de animación 3D calculando el costo de producción individual de cada una de ellas mediante una fórmula ponderada (que multiplica las horas de modelado por 40,000, las horas de render por 25,000 y el número de artistas por 120,000) sin alterar los datos originales; a partir de este cálculo, filtra y aísla de forma automática aquellas escenas críticas que superan un presupuesto límite de 1,000,000, consolida la sumatoria total del impacto financiero del proyecto completo y detecta cuál es la escena específica con el mayor coste, mostrando finalmente todos estos resultados de manera estructurada y limpia en la consola.**
