# Diagrama de arbol
``` md
arquitectura-3d
├── docs/
│   └── convenciones.md
├── materiales/
├── modelos/
├── planos/
└── renders/
```
En base al problema de estrucutra, esta es la solucion que se muestra como diagrama de arbol, en la que cada carpeta tiene un fin especifico.

- en docs: Convenciones.md en el cual se estableceran las reglas del modelado
- materiales: Todo lo necesario para empezar con el modelado
- modelos: Todas las creaciones de modelos
- planos: Bocetos y bosquejos basicos para el modelado
- renders: Despues del modelado, aqui se guardarán para su posterior renderizado
