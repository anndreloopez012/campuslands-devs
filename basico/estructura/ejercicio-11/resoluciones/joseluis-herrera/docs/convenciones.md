# Convenciones de Nomenclatura y Organización - Proyecto 3D

## 1. Reglas Generales de Nomenclatura
* Usar minúsculas en su totalidad.
* Separar las palabras mediante guiones medios (`-`).
* Evitar espacios, tildes, eñes (`ñ`) y caracteres especiales.
* Formato de fecha para versiones específicas (si aplica): `YYYY-MM-DD`.

## 2. Nombres Específicos para Vistas y Renders
* **Fachadas:** `fachada-principal`, `fachada-posterior`, `fachada-lateral-izq`.
* **Interiores:** `vista-interior-sala`, `vista-interior-cocina`.
* **Generales:** `axonometria-general`, `corte-por-escala`.

## 3. Control de Versiones en Directorios
* **Borradores (`/borradores/`):** Archivos en proceso, pruebas de concepto, iluminación preliminar o geometrías sin validar. No deben usarse para entregas a clientes o validación final.
* **Finales (`/finales/`):** Archivos aprobados, optimizados y listos para producción, planos oficiales o renders de alta calidad con post-producción.
