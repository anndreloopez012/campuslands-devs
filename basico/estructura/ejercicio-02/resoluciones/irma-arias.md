# Ejercicio 02: Estructura de Estudio Indie de Videojuegos

**Nombre:** Irma Arias

## Explicación del Problema
He organizado el proyecto siguiendo una arquitectura profesional para videojuegos de acción y aventura, separando el código fuente de los activos multimedia (imágenes, audio, mapas) y documentación necesaria para el desarrollo.

## Árbol de la Solución
- src/ (Código fuente)
- activos/
  - imagenes/
  - audio/
  - mapas/
- documentos/
- pruebas/
- resoluciones/
  - irma-arias.md

## Validación
Cada carpeta que debe permanecer vacía para el inicio del proyecto contiene un archivo `.gitkeep`, asegurando que la estructura sea reconocida por Git sin errores.
