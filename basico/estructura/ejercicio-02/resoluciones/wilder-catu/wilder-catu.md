# Estructura Base del Proyecto

## Descripción

Se creó la estructura principal del proyecto con el objetivo de organizar los archivos según su función, facilitando el desarrollo, el mantenimiento y la escalabilidad de la aplicación.

## Estructura de directorios

```text
proyecto/
│
├── css/
│   └── style.css
│
├── data/
│   └── players.json
│
├── js/
│   └── app.js
│
└── index.html
```

## Descripción de los archivos y carpetas

| Carpeta/Archivo | Descripción |
|-----------------|-------------|
| `index.html` | Archivo principal de la aplicación. Contiene la estructura HTML e integra los archivos CSS y JavaScript. |
| `css/` | Carpeta destinada a almacenar los archivos de estilos del proyecto. |
| `css/style.css` | Archivo que contiene las reglas de estilo y la apariencia visual de la aplicación. |
| `js/` | Carpeta destinada al código JavaScript del proyecto. |
| `js/app.js` | Archivo principal que implementa la lógica y el comportamiento de la aplicación. |
| `data/` | Carpeta destinada a almacenar los archivos de datos utilizados por la aplicación. |
| `data/players.json` | Archivo en formato JSON que almacena la información de los jugadores que será utilizada por la aplicación. |

## Resultado

- Se organizó la estructura inicial del proyecto.
- Se separaron los archivos según su responsabilidad (estructura, estilos, lógica y datos).
- Se estableció una organización que facilita el desarrollo y el mantenimiento del proyecto.
