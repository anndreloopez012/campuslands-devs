
# Estudio de Tatuajes - Gestión de Archivos
**Autora:** Irma Arias

## Privacidad de Datos
La seguridad y privacidad son nuestra prioridad. En este repositorio:
1. **Datos Ficticios:** Solo utilizamos marcadores de posición para pruebas de desarrollo. Está prohibido subir fotografías reales o datos personales de clientes.
2. **Cifrado:** Cualquier base de datos de clientes debe ser tratada bajo protocolos de cifrado.
3. **Acceso Restringido:** Solo personal autorizado tiene acceso a la información del cliente.

## Estructura del Proyecto
- `referencias/`: Catálogo de estilos y fuentes de inspiración visual.
- `disenos/`: Bocetos, plantillas y fichas técnicas de los proyectos.
- `clientes/`: Gestión de información (datos protegidos).
- `agenda/`: Programación de citas y control de tiempos.
