# Resolucion ejericicio 09 de estructura

```text
└─ tatuajes
   ├─ agendas/
   ├─ clientes/
   ├─ diseños/
   ├─ referencias/
   └─ readme.md
```

_Explicacion_: En base a las estrucutras del reame.md, el diagrama de arbol que se muestra.
Ademas dentro de cada carpeta va lo siguiente:
- agendas: Es donde se almacenara un archivo json para los datos de los horarios de atencion programados
- clientes: Es donde se almacenaran los datos de los clientes, los cuales no seran expuestos al publico najo ningun motivo
- diseños: Aqui es almacenarán las imagenes de los diseños de los tatuajes y sus descripciones
- referencias: Es donde estarán los datos de figuras publicas con tatuajes que se pueden replicar para el usuario que desee, siempre y cuando sea viable
