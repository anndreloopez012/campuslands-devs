## Explicacion de porque no combiene mezclar imagenes con datos 
El motivo por el cual no se conviene mezclar este tipo de datos es por la razón de que se puede crear una carpeta unica para imagenes y una carpeta de datos para asi poder tener todo organizado y ordenado sin la necesidad de mezclar imagenes con datos ademas de eso las imagenes pueden llegar a tener un mayor peso en los datos afectadando la base de datos o el rendimiento.

## Explicacion de como se trabajo el proyecto 
Se organizo el proyecto por pasos primero se crearon las carpetas principales para seguir con las subcarpetas que llevaria cada carpeta principal y termiando con los archivos que se nos pidieron
teniendo una organizacion adecuada para la estructura de un proyecto.
