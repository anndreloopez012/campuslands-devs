# Explicacion 
Se estructuró una base de datos y un sistema de desarrollo para un proyecto técnico de fútbol, organizado en tres directorios principales: data, docs y src. Cada carpeta contiene sus archivos esenciales de configuración y documentación correspondientes. Con esta arquitectura, se busca optimizar la gestión de la información de ligas, equipos y partidos, garantizando que el equipo mantenga un entorno de trabajo escalable y ordenado.
