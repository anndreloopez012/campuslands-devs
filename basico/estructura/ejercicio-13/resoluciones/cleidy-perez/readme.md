# Panel Deportivo Multiliga

## Nombre

Cleidy Pérez

## Objetivo

Organizar un proyecto para administrar equipos, partidos y tablas de diferentes ligas deportivas.

## Proceso

1. Crear la estructura de carpetas.
2. Separar la información de equipos y partidos.
3. Organizar los archivos por liga.
4. Crear el modelo de datos.
5. Agregar un ejemplo de tabla.
6. Validar que la estructura pueda crecer fácilmente.

## Resultado

Se obtuvo una estructura ordenada que facilita agregar nuevas ligas y mantener organizada la información.

## Validación

### Caso normal

Las carpetas principales fueron creadas correctamente.

### Caso límite

Los archivos están separados por liga y la documentación requerida existe.
