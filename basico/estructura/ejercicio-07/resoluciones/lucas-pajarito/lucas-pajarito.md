# Ejercicio 07 

### DESCRIPCION
Este ejercicio está diseñado para que practiques análisis, orden y toma de decisiones. Aunque pertenece al nivel básico, debes tratarlo como una tarea real: leer requisitos, transformar información en una solución y validar el resultado.

## 1. NOMBRAR PORTADAS

Para mantener un orden en los archivos, las portadas deben seguir el formato:

```
Tema_Nombre_Apellido.pdf
```

**Ejemplo:**

```
JavaScript_Lucas_Pajarito.pdf
```

## 2. PLANTILLA DE RESEÑAS.

Utiliza la siguiente estructura para todas las reseñas:

* **Título**
* **Autor**
* **Fecha**
* **Resumen:** Breve descripción del contenido.
* **Opinión:** Análisis o comentario personal.
* **Conclusión:** Idea principal o aprendizaje obtenido.

Seguir este formato facilita la organización y la revisión de los documentos.
