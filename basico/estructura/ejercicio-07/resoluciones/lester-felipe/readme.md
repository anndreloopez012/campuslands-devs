## Descripcion:
Una buena estructura de carpetas antes de empezar a trabajar un proyecto grande, asegura un código altamente escalable, limpio y fácil de mantener en entornos reales de desarrollo.

## Explicacion de las carpetas
```
mi-coleccion-scifi/
│
├── books/
│   ├── data/
│   │   └── duna.json                   # Datos estructurados del libro (Meta-información)
│   │
│   └── covers/
│       ├── README.md                   # Documentación sobre el nombrado de portadas
│       └── duna-1965.jpg               # Imagen de la portada (Recurso)
│
├── reviews/
│   ├── plantilla-resena.md             # Plantilla base para redactar nuevas reseñas
│   └── resena-duna.md                  # Reseña de ejemplo completada (Contenido)
│
└── README.md                           # Descripción general del proyecto
