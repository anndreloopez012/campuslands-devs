
# Convenciones de Versionado de Audio

- **Formato obligatorio:** `nombre-cancion-vXX.wav`
  - Ejemplo: `melodia-principal-v01.wav`
- **Reglas de oro:**
  - Los archivos en `masters/` nunca se mezclan con `mezclas/` o `pistas/` para evitar confusiones en la distribución final.
  - El uso de versiones (`v01`, `v02`) es obligatorio para evitar sobrescritura accidental.
