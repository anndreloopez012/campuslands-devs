# Archivo Musical para Productores
**Autora:** Irma Arias

## Razonamiento
Se ha diseñado esta estructura para separar el material crudo (pistas y samples) de los resultados procesados (mezclas y masters). La separación de los masters es fundamental, ya que representan la versión final y aprobada, debiendo estar aislados de las iteraciones de mezcla para garantizar la integridad de la entrega.

## Estructura
- `pistas/`: Grabaciones crudas.
- `samples/`: Librería de sonidos.
- `mezclas/`: Archivos en proceso de balance.
- `masters/`: Archivos finales listos para distribución.
- `docs/`: Documentación y convenciones de nombres.
