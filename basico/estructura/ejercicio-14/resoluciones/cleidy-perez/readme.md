# Archivo Musical para Productores

## Nombre

Cleidy Pérez

## Objetivo

Organizar un proyecto musical separando canciones, samples, mezclas, masters y documentación.

## Proceso

1. Crear las carpetas principales.
2. Organizar las canciones por versión.
3. Separar los samples y las mezclas.
4. Guardar los masters en una carpeta independiente.
5. Documentar la convención de nombres.
6. Validar la estructura.

## ¿Por qué los masters no se mezclan con los borradores?

Los archivos **master** representan la versión final aprobada del proyecto. Mantenerlos separados evita modificaciones accidentales y facilita identificar cuál es el archivo listo para distribución.

## Resultado

Se obtuvo una estructura organizada que facilita el control de versiones y el almacenamiento de archivos de producción musical.

## Validación

### Caso normal

Todas las carpetas requeridas fueron creadas.

### Caso límite

Los masters permanecen separados de los archivos en proceso y los nombres siguen la convención establecida.
