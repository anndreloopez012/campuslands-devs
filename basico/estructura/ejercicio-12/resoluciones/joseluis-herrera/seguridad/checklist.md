# Checklist de Seguridad para Trabajos de Soldadura

## 1. Equipo de Protección Personal (EPP)
* [ ] Careta de soldar con filtro de sombra adecuado (según proceso SMAW, GMAW o GTAW).
* [ ] Guantes de cuero de manga larga (resguardos para alta temperatura).
* [ ] Mandil o peto de carnaza.
* [ ] Casaca o polainas de cuero (si aplica por posición de soldadura).
* [ ] Zapatos de seguridad con casquillo de acero y suela dieléctrica.
* [ ] Respirador con filtros para humos metálicos (especial para humos de soldadura).

## 2. Inspección del Área de Trabajo
* [ ] Retirado todo material inflamable o combustible en un radio de 10 metros.
* [ ] Extintor de PQS (Polvo Químico Seco) o CO2 verificado y accesible.
* [ ] Pantallas o mamparas de protección contra radiación UV instaladas.
* [ ] Ventilación del área comprobada (extracción de humos activa).

## 3. Revisión de Equipos y Herramientas
* [ ] Máquina de soldar desconectada antes de realizar conexiones o mantenimientos.
* [ ] Cables de poder, pinza portaelectrodo y pinza de masa sin cortes, aislamientos dañados ni falsos contactos.
* [ ] Líneas de gas de protección (en caso de procesos MIG/TIG) libres de fugas y manómetros calibrados.
