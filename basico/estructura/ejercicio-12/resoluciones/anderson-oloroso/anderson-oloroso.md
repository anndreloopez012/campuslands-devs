# Diagrama de árbol
``` md
soldadura-industrial
├── evidencias
├── materiales
│   └── catalogo.md
├── practicas
└── seguridad
    └── checklist.md 
```

Considerando todas la necesidades de la organizacion de archivos para el taller de soldadura industrial, se obtuveo el diagrama de arbol.

- evidencias: Se almacenarán evidencias de cuallquier suceso dentro del taller
- materiales: Se almacenará un catálogo en el cual se podá llevar un correcto control de los registros de los materiales
- prácticas: Se almacenarán cualquier proyecto del taller como parte del aprendizaje y dessarrollo de todos
- seguridad: Aqui se alamcenara un checklist para poder revisar que todas las personas lleven el correcto EPP para cada trabajo
