# Criterios y Gestión de Evidencias

Para mantener un registro limpio y ordenado del proyecto, se definen las siguientes normas de aceptación de evidencias:

## Evidencias Aceptadas
1. **Fotografías del cordón de soldadura:** Imágenes en formato `.jpg` o `.png` con buena iluminación que muestren la apariencia visual del cordón.
2. **Reportes de Inspección No Destructiva (IND):** Archivos `.pdf` firmados que certifiquen pruebas de líquidos penetrantes o ultrasonido.
3. **Registro de Parámetros:** Formatos en código o tablas Markdown con los valores de amperaje, voltaje y velocidad de avance.

## Regla de Organización
- Los reportes escritos y archivos de texto deben mantenerse separados en las carpetas correspondientes y nunca mezclados directamente con carpetas de imágenes crudas.
