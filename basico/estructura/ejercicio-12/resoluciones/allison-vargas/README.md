## Solución del Problema
Se estructuró una base ordenada de archivos para un proyecto técnico de soldadura industrial dividida en 4 módulos principales:

1. `practicas/`: Espacio destinado a las guías y registros de ejecución de prácticas.
2. `materiales/`: Catálogo detallado de insumos y consumibles de soldadura (`catalogo.md`).
3. `seguridad/`: Lista de verificación de medidas de seguridad y EPP (`checklist.md`).
4. `evidencias/`: Lineamientos y documentos de aceptación de evidencia de trabajos (`README.md`).

## Razonamiento Técnico
El problema se abordó separando las responsabilidades por carpeta para evitar la mezcla de reportes, listas de seguridad y registros visuales. Se aseguró cumplir con la regla de no mezclar archivos base ni modificar la estructura externa.
