
# Registro de Soldadura Industrial
**Autora:** Irma Arias

## Descripción
Estructura organizada para el registro de prácticas, gestión de materiales y protocolos de seguridad en soldadura.

## Estructura
- `practicas/`: Bitácoras de trabajo.
- `materiales/`: Catálogo de insumos.
- `seguridad/`: Normas y checklist.
- `evidencias/`: Registros fotográficos e informes técnicos.
