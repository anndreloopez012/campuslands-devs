## Descripcion.

Este ejercicio está diseñado para que practiques análisis, orden y toma de decisiones. Aunque pertenece al nivel básico, debes tratarlo como una tarea real: leer requisitos, transformar información en una solución y validar el resultado.

### EXPLICACIÓN DE ARCHIVOS Y CARPETAS.

___CONFIG___:
 La carpeta ``Config`` (o archivos .``config``) funciona principalmente como un almacén de parámetros y ajustes iniciales para aplicaciones, procesos de servidor y sistemas operativos.  Su trabajo es centralizar la información de configuración necesaria para que el software se comporte según las necesidades específicas del usuario o la organización, permitiendo la personalización sin modificar el código fuente

___DOCS___ : El principal trabajo de la carpeta docs es almacenar archvivos como: instrucciones, manuales de ejecucion, archivos de investigacion, etc.


___MODULES___ : El funcionamiento principal de una carpeta ``node_modules`` (típica de Node.js y NPM) es almacenar todas las dependencias y librerías externas que un proyecto necesita para funcionar.  Cuando se ejecuta el comando npm install, NPM descarga los paquetes especificados en el archivo package.json y los coloca en esta carpeta, junto con sus propias dependencias anidadas, permitiendo que el código las importe y utilice mediante sentencias como require() o `import`
