## Convenciones para nombrar imágenes de autos

Para mantener la consistencia en la carpeta `assets/cars`, se deben seguir las siguientes reglas al subir imágenes:

1. **Formato:** Utilizar minúsculas exclusivamente.
2. **Separador:** Usar guiones medios (`-`) para separar las palabras.
3. **Estructura base:** `[marca]-[modelo]-[año].[extensión]`
   * Ejemplo correcto: `toyota-corolla-2022.jpg`
   * Ejemplo incorrecto: `Toyota Corolla (2022).JPG`
4. **Extensiones permitidas:** `.jpg`, `.jpeg`, `.png` o `.webp`.
