# Sistema de Carreras Urbanas

## Nombre

Cleidy Pérez

## Objetivo

Organizar un simulador de carreras con pilotos, vehículos, pistas y resultados de forma ordenada.

## Proceso

1. Crear las carpetas principales.
2. Separar los datos de pilotos, vehículos y pistas.
3. Crear la carpeta del simulador.
4. Documentar las reglas de la carrera.
5. Mantener la configuración separada de los resultados.
6. Validar que cada carpeta tenga un propósito definido.

## Propósito de cada carpeta

- **data/**: almacena la información de pilotos, vehículos y pistas.
- **src/simulador/**: contiene la lógica del simulador.
- **config/**: guarda la configuración de la simulación.
- **resultados/**: almacena los resultados obtenidos.
- **docs/**: contiene la documentación del proyecto.

## Validación

### Caso normal

Todas las carpetas y archivos requeridos fueron creados.

### Caso límite

Cada carpeta tiene un propósito claro y la configuración está separada de los resultados.
