
# Reglas del Sistema de Carreras Urbanas

1. **Pilotos:** Deben estar registrados con licencia vigente.
2. **Vehículos:** Cada hiperdeportivo debe tener ficha técnica completa (velocidad, aceleración, agarre).
3. **Pistas:** Clasificadas por dificultad (urbana, circuito, montaña).
4. **Resultados:** Se generan tras procesar la interacción entre piloto y vehículo en la pista seleccionada.
