## Solución ejercicio: Estructura ejercicio 15

- **Henrik Anderson Oloroso García**.
- La solución completa.

```txt
hiperdeportivos/
├─ data/
│  ├─ pilotos/
│  │  └─ pilotos.json
│  ├─ vehiculos/
│  │  └─ vehiculos.json
│  └─ pistas/
│     └─ pistas.json
├─ src/
│  └─ simulador/
│     └─ simulador.md
├─ results/
│  └─ results-config.json
└─ docs/
   ├─ reglas-carrera.md
   └─ info.md
```
- Breve explicación.
_Explicación:_ Separé el proyecto por responsabilidades para que cada parte tenga un propósito claro: data/ para los archivos base del simulador (pilotos, vehículos y pistas), src/simulador/ para la guía/lógica del simulador, docs/ para documentar reglas de carrera y contexto, y results/ para guardar la configuración de resultados; esto facilita validar el proyecto y mantener el orden.
