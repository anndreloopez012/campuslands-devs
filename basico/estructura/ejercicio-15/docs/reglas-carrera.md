# Reglas de Carrera

1. **Pilotos:** Deben estar registrados con licencia vigente.
2. **Vehículos:** Deben cumplir con las especificaciones técnicas de la categoría.
3. **Pistas:** La simulación se basará en la longitud y el tipo de trazado (asfalto/urbano).
4. **Resultados:** Se generan tras procesar la interacción entre piloto, vehículo y pista.
