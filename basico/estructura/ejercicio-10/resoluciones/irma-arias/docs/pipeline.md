
# Pipeline de Animación 3D

## Gestión de Versiones
Para evitar confusiones, seguimos esta nomenclatura: `nombre_v001.ext`.
- **Archivos de prueba:** Se guardan con sufijo `_test` o `_wip` (Work In Progress).
- **Archivos finales:** Se guardan solo en la carpeta `04-entregas` una vez aprobados.
- **Validación:** Nunca se sobrescriben archivos; se crean nuevas versiones incrementales.
