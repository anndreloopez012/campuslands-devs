
# Pipeline de Animación 3D
**Autora:** Irma Arias

## Razonamiento
He diseñado este flujo de trabajo para garantizar que los recursos pesados (texturas y renders) no se mezclen con la lógica del proyecto (modelado). La numeración (`01-`, `02-`, etc.) asegura un orden alfabético que coincide con el orden cronológico del proceso de animación.

## Estructura
- `01-modelado/`, `02-texturas/`, `03-renders/`: Fases técnicas del pipeline.
- `04-entregas/`: Archivos validados para entrega final.
- `referencias/`: Inspiración visual.
- `docs/`: Documentación del pipeline.
