## Explicacion
Se realizo la organizacion de carpetas para un Pipeline de animación 3D en las carpetas principales fueron modelado, texturas, renders, entregas, docs y referencias lo que se busca con esta
orgnaizacion es de que el la pipeline pueda tener toda a la mano de una mejor manera y obtener los datos y informacion de una manera rapida y precisa.

## Como evitar confusiones de archivos finales y pruebas
Para evitar estos conflictos se crearia otra carpeta llamada pruebas y ahi meter todas las pruebas
que se le dan al cliente para que observer el producto y los archivos finales se pondrian en la carpeta entregas.
