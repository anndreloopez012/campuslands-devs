
# Pipeline de Producción 3D

## Estructura de Trabajo
- **01-modelado**: Archivos fuente (.blend, .obj).
- **02-texturas**: Mapas UV y materiales.
- **03-renders**: Pruebas de renderizado.
- **04-entregas**: Archivos finales para cliente.

## Gestión de Versiones
Para evitar confusiones, los archivos finales deben llevar el sufijo `_vFinal`. Las pruebas se nombrarán con `_test_fecha`. Nunca se sobreescribe un archivo; se crea una nueva versión.
